# Changelog

## 0.1.3

- Render CSS property names in the neutral foreground so stylesheets retain a calm hierarchy.
- Keep coral focused on HTML, XML, and JSX attributes.
- Route Rust attributes such as `#[derive]` and `#[tauri::command]` to the mauve decorator family instead of the markup-attribute color.
- Document deferred Markdown and secondary-metadata refinements for a later focused pass.

## 0.1.2

- Render object, JSON, and YAML keys in the neutral foreground instead of a keyword-adjacent warm color.
- Render semantic properties and fields neutrally for calmer data-heavy code.
- Preserve coral for lower-frequency attribute syntax such as HTML attributes and CSS property names.

## 0.1.1

- Render readonly and static variable names in the neutral foreground instead of mauve.
- Keep mauve reserved for actual constants, enum members, and numeric values.
- Apply the calmer variable treatment consistently to Emberveil and Emberveil Dark.

## 0.1.0

- First usable release of Emberveil and Emberveil Dark.
- Covers the VS Code workbench, editor states, syntax, semantic tokens, terminal ANSI colors, Git decorations, diffs, diagnostics, notebooks, and testing UI.
