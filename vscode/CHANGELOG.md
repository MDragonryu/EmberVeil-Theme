# Changelog

## 0.1.1

- Render readonly and static variable names in the neutral foreground instead of mauve.
- Keep mauve reserved for actual constants, enum members, and numeric values.
- Apply the calmer variable treatment consistently to Emberveil and Emberveil Dark.

## 0.1.0

- First usable release of Emberveil and Emberveil Dark.
- Covers the VS Code workbench, editor states, syntax, semantic tokens, terminal ANSI colors, Git decorations, diffs, diagnostics, notebooks, and testing UI.
