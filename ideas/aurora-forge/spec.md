# Aurora Forge

**Status:** Independent concept theme, prototype study 02  
**Primary mode:** Dark  
**Preview:** [preview.html](preview.html)

## Purpose

Aurora Forge explores what happens when several historically important theme preferences are intentionally combined: Ayu Mirage, Nord, Cobalt2, JetBrains/Darcula, and the creator's manually configured Delphi palette.

The theme was designed as a broad synthesis rather than a refinement of the Delphi setup. Its goal was to make each influence visibly present while still producing a usable editor and application system.

## Initial direction

The design assigned a distinct responsibility to every influence:

- **Ayu Mirage** contributed warm syntax relationships and an atmospheric editor.
- **Nord** contributed layered dark surfaces, Frost-like structural colors, and calm UI hierarchy.
- **Cobalt2** contributed saturated blue chrome, golden focus, and energetic contrast.
- **JetBrains/Darcula** contributed practical semantic separation and substantial editor states.
- **The personal Delphi configuration** contributed orange control flow, green comments, a dark current line, and restrained plain text.

The result is intentionally more colorful and more overtly "IDE themed" than Vermilion Fjord.

## Core character

Aurora Forge feels energetic, technical, and polished. Deep cobalt surfaces make the workbench visibly blue, while orange, gold, cyan, green, and mauve create a complete semantic spectrum.

The experience can be summarized as:

> A deep cobalt workbench lit by warm forge colors and arctic semantic accents.

This is a strong theme for users who enjoy pronounced UI color and want different syntax categories to be recognizable immediately.

## Syntax language

Aurora Forge uses explicit semantic differentiation:

- **Keywords** are orange.
- **Functions and method calls** are gold.
- **Types, classes, and primitives** are cyan.
- **Strings** are green.
- **Numbers and constants** are mauve.
- **Properties and member fields** are coral.
- **Operators and punctuation** use a cool steel blue.
- **Comments** use an olive green and may be italic.
- **Tags** use a brighter cyan.

Unlike Vermilion Fjord, this theme expects modern semantic token support and benefits from editors that can distinguish functions, properties, types, variables, and declarations.

## Interface behavior

Aurora Forge treats the entire IDE chrome as part of the theme identity:

- Activity bars and sidebars use deep cobalt surfaces.
- Selected navigation items use brighter blue and an orange edge.
- Active editor tabs use a golden focus line.
- Primary actions remain orange.
- Status and selection states use cyan and blue.
- Terminal surfaces become deeper navy rather than neutral charcoal.

The UI is meant to feel continuous with the syntax rather than merely surrounding it.

## What makes Aurora Forge unique

Aurora Forge is the most visibly synthetic and expansive theme study. It demonstrates that the creator still appreciates the high-energy blue-and-gold character associated with Cobalt2 while also preferring the more nuanced semantic palette of Ayu Mirage and Nord.

Its defining strength is confidence: the theme looks complete at first glance and would be immediately recognizable in a marketplace. Its defining limitation is the same trait. The pervasive cobalt workbench makes it feel closer to an earlier generation of the creator's taste than to the current Ayu Mirage-led direction.

## Boundaries

Aurora Forge should remain blue-forward. Removing the cobalt chrome would turn it into a different theme rather than a refinement. It should also retain the golden focus color and full semantic palette.

The theme should not be treated as the canonical Emberveil family. It is an independent branch that may appeal to users who want more saturation, sharper differentiation, and a visibly colored workbench.

## Future development

Potential implementations include:

- A VS Code theme with strong workbench theming and semantic token support.
- A JetBrains color scheme and UI theme.
- A terminal palette using the deep navy and gold relationship.
- An optional "high energy" application theme for dashboards and developer tools.

Aurora Forge should be preserved as evidence of an important taste lineage and as a viable independent theme, not discarded simply because Emberveil became the stronger personal direction.
